Aim: Write basic Linux commands with options and examples.

--------------------------------------------------------------
1. date
--------------------------------------------------------------
Purpose : Print the date and time.
Syntax  : date [options] [+format]
Example : $ date
Output  : Mon Jul 28 09:59:00 IST 2025

Format options (used as  date +%X):
  %a  Abbreviated weekday name            $ date +%a   ->  Mon
  %A  Full weekday name                   $ date +%A   ->  Monday
  %b  Abbreviated month name              $ date +%b   ->  Jul
  %B  Full month name                     $ date +%B   ->  July
  %c  Locale's date and time              $ date +%c   ->  Mon Jul 28 20:58:46 2025
  %D  Date as mm/dd/yy                    $ date +%D   ->  07/28/25      [FIXED: was 07/028/25]
  %j  Day of year (001-366)               $ date +%j   ->  209
  %n  Insert a new line
        $ date +"Date is %D%nTime is %T"
        Date is 07/28/25
        Time is 21:14:58
  %p  AM or PM                            $ date +%p   ->  PM
  %T  Time as HH:MM:SS (24 hour)          $ date +%T   ->  21:18:54
  %t  Insert a tab
        $ date +"Date is %D%tTime is %T"
        Date is 07/28/25    Time is 21:18:54
  %V  ISO week number of year (01-53), week starts on Monday   [FIXED: range is 01-53]
        $ date +%V   ->  31
  [ADDED] %Y  4-digit year   $ date +%Y -> 2025
  [ADDED] %d  Day of month   $ date +%d -> 28
  [ADDED] %H:%M  Hour and minute

--------------------------------------------------------------
2. who
--------------------------------------------------------------
Purpose : List users currently logged in, their terminal, login
          time and the host they logged in from.
Syntax  : who [options] [file]
Example : $ who -uH
Output  :
  NAME   LINE   TIME           IDLE   PID    COMMENT
  hiox   tty3   Jul 10 11:08   .      4578

Options:
  am i : Print the username of the invoking user ('am' and 'i' must be
         space separated).                       $ who am i
  -b   : Time of last system boot.                $ who -b
  -d   : Print dead processes.                    $ who -d
  -H   : Print column headings above the output.  $ who -H
  -i   : (older) include idle time; today use -u. $ who -u
         Idle time '.' means activity within the last minute.
  -m   : Same as  who am i                        $ who -m
  -q   : Print only usernames and the count of logged-in users.
                                                  $ who -q
  -T, -w : Include the user's message status (+ writable, - not).
                                                  $ who -T
                                                  $ who -w

--------------------------------------------------------------
3. echo
--------------------------------------------------------------
Purpose : Print the given string to standard output.
Syntax  : echo [options] [string]
Example : $ echo "Hi, I am Savani"
Output  : Hi, I am Savani

Options:
  -n : Do not output the trailing newline.
         $ echo -n "This is newline."
  -e : Enable interpretation of backslash escapes.
  -E : Disable interpretation of backslash escapes (default).

Escape sequences recognised with -e:
  \0NNN  Character whose ASCII code is NNN (octal)
           $ echo -e "\0101"      ->  A      [FIXED: \0101 prints A]
  \a     Alert (bell)             $ echo -e "\a"
  \\     Backslash                $ echo -e "\\"
  \b     Backspace                $ echo -e "Hi\bX"        ->  HX
  \c     Suppress trailing newline (and stop output)
           $ echo -e "Hello\c"; echo "World"       ->  HelloWorld
  \f     Form feed
           $ echo -e "Hello World\fThis is Linux Programming"
  \n     New line
           $ echo -e "Hello\nWorld"       ->  Hello
                                              World
  \r     Carriage return (cursor goes back to start of line)
           $ echo -e "Hello\rWorld"       ->  World
  \t     Horizontal tab           $ echo -e "Hello\tWorld"  ->  Hello    World
  \v     Vertical tab             $ echo -e "Hello\vWorld"

  -e : Expire the password so user must change it at next login. $ passwd -e user

1. cat
--------------------------------------------------------------
Purpose : Concatenate files and print on standard output.
Syntax  : cat [options] [file]
Options :
  -A : Show all (same as -vET).
  -b : Number only non-blank output lines.        [FIXED]
  -e : Show $ at end of each line, and show non-printing chars (-vE).
  -E : Display a $ at the end of each line.
  -n : Number all output lines.
  -s : Squeeze multiple empty lines into one.
  -T : Display TAB characters as ^I.
  -v : Show non-printing characters visibly (except TAB / newline).

(a) Create a new file
    Syntax  : $ cat > file.txt       (press Ctrl+D to save and exit)
    Example : $ cat > student.txt
      RollNo | Name              | Class       | Address    | Mob.No
      101    | Savani Rajopadhye | T.Y.BSc(CS) | Kothrud    | 8475560890
      102    | Siddhi Jadhav     | T.Y.BSc(CS) | Kothrud    | 9470554400
      103    | Shreeya Mohanta   | T.Y.BSc(CS) | Paud       | 8874415801
      104    | Gayatri Pawar     | T.Y.BSc(CS) | Bavdhan    | 7541101592
      105    | Soundarya Sadekar | T.Y.BSc(CS) | Navi Peth  | 9824568700

(b) Append data to a file
    Syntax  : $ cat >> file.txt
    Example : $ cat >> student.txt
    Purpose : Use the append operator (>>). With a single > the
              file is overwritten (all old content erased).

(c) Display a file
    Syntax  : $ cat file.txt
    Example : $ cat student.txt

(d) Concatenate several files and display
    Syntax  : $ cat file1.txt file2.txt
    Example : $ cat student.txt marks.txt
    Output  : student details followed by the Marks column
              (98, 95, 92, 90, 94).

(e) Concatenate several files and store output in another file
    Syntax  : $ cat file1.txt file2.txt > file3.txt
    Example : $ cat student.txt marks.txt > file.txt
    Output  : Creates file.txt containing the combined content.

5. cp
--------------------------------------------------------------
Purpose : Copy files from one location to another.
Syntax  : cp [options] source dest
          cp [options] source... directory
          cp [options] --target-directory=DIRECTORY source...
Example : $ cp file1 file2       (copies content of file1 to file2)
Options :
  -a : Same as -dpR (archive; preserve everything, recursive).
  --backup[=CONTROL] : Make a backup of each existing destination file.
  -b : Like --backup but does not accept an argument.
  -f : If an existing destination cannot be opened, remove it and retry.
  -p : Preserve specified attributes.
  --preserve[=ATTR_LIST] : Preserve mode, ownership, timestamps (default).
  --no-preserve=ATTR_LIST : Don't preserve the specified attributes.
  --parents : Append source path to DIRECTORY.
  -r / -R : [ADDED] Copy directories recursively.
  -i : [ADDED] Prompt before overwrite.
  -v : [ADDED] Verbose.

6. ls
--------------------------------------------------------------
Purpose : List files and directories in the current directory.
Syntax  : ls [options] [file]
Example : $ ls
Output  : Student  addressbook  student.txt  marks.txt  file1  file2
Options :
  -l   : Long listing: mode, links, owner, group, size, modified date/time, name.
  -t   : Sort by last modification time.
  -a   : List all entries including hidden files.
  -d   : List directories themselves instead of their contents.
  -p   : Put a slash at the end of each directory name.
  -u   : Sort by last access time.
  -i   : Display inode numbers.
  -ltr : Long listing, oldest first (sorted by date).
  -lSr : Long listing, smallest first (sorted by file size).

Options :

--------------------------------------------------------------

  -u : Show only non-repeated lines.

##############################################################
 EXPERIMENT 3 : PATTERN MATCHING COMMANDS (grep, sed)
##############################################################

Aim: Write pattern matching commands of Linux with options and examples.

--------------------------------------------------------------
1. grep  -  search for a pattern
--------------------------------------------------------------
Syntax  : grep [options] pattern [filenames]
Example : $ grep "sales" emp.lst
Output  : all lines containing "sales"
Options :
  -i : Ignore case.
  -v : Display lines NOT matching the pattern.
  -n : Display line numbers along with the lines.
  -c : Display count of matching lines.
  -l : Display only names of files containing the pattern.
  -f : Take patterns from a file, one per line.

Regular-expression characters:
 i)  [ ]  Character class - any one character from the set.
       $ grep "[aA]g[ar]wal" emp.lst
       3564|sudhir Agarwal|executive|personnel|01/06/47|7500
       0110|v.k. agrawal  |g.m.     |marketing |12/31/40|9000
 ii) *    Zero or more of the immediately preceding character.
       $ grep "[aA]gg*[ar]wal" emp.lst
 iii) .   Matches any single character.
       $ grep "j.*saxena" emp.lst
       2345|j.b. saxena|g.m.|marketing|03/12/45|8000
 iv) ^    Matches pattern at the beginning of a line.
       $ grep "^2" emp.lst      (lines starting with 2)
 v)  $    [ADDED] Matches pattern at the end of a line.
       $ grep "0$" emp.lst
 vi) Multiple patterns (extended regex, grep -E / egrep):
       $ grep -E 'sengupta|dasgupta' emp.lst
       2305|barun sengupta|director|personnel|11/05/47|7800
       1265|s.n. dasgupta |manager |sales    |12/09/63|5600

--------------------------------------------------------------
2. sed  -  stream editor (combines the work of several filters)
--------------------------------------------------------------
Syntax  : sed [options] 'address action' file(s)
Example : $ sed '2q' emp.lst        (print first 2 lines, then quit)
Output  :
  2233|a.k. shukla|g.m     |sales     |12/12/52|6000
  9876|jai sharma |director|production|03/12/50|7000
Options / commands:
  -n : Suppress automatic printing (use with p).      [FIXED: p is a command]
  p  : Print the selected lines.
  q  : Quit.

1) Context addressing  /pattern/ - select lines by pattern.
     $ sed -n '/director/p' emp.lst
     9876|jai sharma     |director|production|03/12/50|7000
     2365|barun sengupta |director|personnel |05/11/47|7800
     1006|chanchal singh |director|sales     |09/03/48|6700

3) Text editing
   a) i, a, c  -  insert, append, change
        i = insert text before the line
        a = append text after the line
        c = change (replace) the line
      Example:
        $ sed '1i\
        > #include <stdio.h>\
        > #include <unistd.h>
        > ' foo.c

   b) d  -  delete lines.
        $ sed '2d' emp.lst        (delete line 2)
        $ sed '/director/d' emp.lst

   c) s  -  Substitution
        Purpose : Replace a pattern in its input with something else.
        Syntax  : [address]s/expression1/expression2/flags
        Example : $ sed 's/|/:/' emp.lst | head -n 2
        Output  :
          2233:a.k. shukla|g.m     |sales     |12/12/52|6000
          9876:jai sharma |director|production|03/12/50|7000
        (without the g flag only the FIRST | on each line is replaced;
         use 's/|/:/g' to replace all)

   d) \( \)  -  sed "remembers" the matched pattern and stores it in \1.
        Example : $ sed -n '/marketing/s/director/member/p' emp.lst
        Output  : 6521|lalit chowdary|member|marketing|09/26/45|8200

##############################################################
 EXPERIMENT 5 : CONDITIONAL AND LOOP STRUCTURES USING AWK
##############################################################

CONDITIONAL STATEMENTS
----------------------
1. if statement  -  check whether a number is positive.
   $ awk 'BEGIN { num=10; if (num > 0) printf "%d is positive number\n", num }'
   Output : 10 is positive number

2. if-else  -  check whether a number is even or odd.
   $ awk 'BEGIN {
       num = 12;
       if (num % 2 == 0)
           printf "%d is even number\n", num;
       else
           printf "%d is odd number\n", num
   }'
   Output : 12 is even number

LOOP STATEMENTS
---------------
1. for loop  -  square of numbers 1 to 6.
   $ awk 'BEGIN { for (i = 1; i <= 6; i++) print "Square of", i, "is", i*i }'
   Square of 1 is 1

1. Armstrong number
   echo "Enter a number"
   read c
   x=$c
   sum=0
   while [ $x -gt 0 ]
   do
       r=$(( x % 10 ))
       n=$(( r * r * r ))
       sum=$(( sum + n ))
       x=$(( x / 10 ))
   done
   if [ $sum -eq $c ]
   then
       echo "It is an Armstrong Number."
   else
       echo "It is not an Armstrong Number."
   fi
   Output : Enter a number : 154
            It is not an Armstrong Number.
            Enter a number : 153
            It is an Armstrong Number.
